---
title: "AI assistant sidebar"
description: "Show, hide, and understand the AI assistant on desktop and mobile in Sure"
---

Sure includes an AI assistant on both desktop and mobile. On desktop it appears as a right-hand sidebar; on mobile it is accessible from the bottom navigation bar.

## Hide or show the AI sidebar on desktop

On desktop, use the **panel-right** button in the top bar to toggle the right-hand AI sidebar.

- Click it once to collapse the AI sidebar
- Click it again to reopen the AI sidebar
- Sure saves this preference to your account

This is useful if you want more room for the main app content or simply do not want to use the assistant yet.

## Accessing the assistant on mobile

On mobile, tap **Assistant** in the bottom navigation bar to open the AI chat interface.

If AI has not been enabled for your account yet, tapping Assistant shows the consent screen rather than the chat composer. This lets you review and accept the AI terms before starting a conversation. Once you accept, the full chat interface becomes available.

## When the sidebar is hidden by default

Sure can also hide the AI sidebar by default for some people:

- New `member` and `guest` users start with the AI sidebar hidden when AI is not available
- `admin` users still see it by default so they can finish AI setup or troubleshooting

If AI becomes available later, you can reopen the sidebar at any time with the same desktop toggle.

## Chat titles

When you start a new chat without providing a custom title, Sure generates a default title using your current language and a timestamp. For example, "New chat 2026-08-31 14:30" in English, "Neuer Chat 2026-08-31 14:30" in German, or "Novo chat 2026-08-31 14:30" in Brazilian Portuguese. You can rename any chat at any time using the edit icon next to its title.

## Localized chat interface

The full chat interface is localized to match your language setting. This includes the AI greeting, suggested questions, chat navigation labels, consent dialog, and error messages. Brazilian Portuguese (pt-BR) is fully supported. Set your language under Settings → Preferences to switch the chat interface to your preferred language.

## Error messages from the AI provider

When the AI provider returns an error during a conversation — for example, a rate-limit or quota error from OpenAI — Sure surfaces the actual error message from the provider. This makes it easier to understand what went wrong and whether the issue is temporary (such as hitting a usage limit) or requires action (such as checking your API key or plan).
