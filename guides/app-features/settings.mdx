# Settings

Sure provides various settings to customize your experience and control how the app behaves.

## Security settings

### High-resolution logos

Sure can fetch high-resolution logos for merchants, financial institutions, and cryptocurrencies using the Brandfetch service. This feature enhances the visual appearance of your transactions, accounts, and holdings.

**To enable high-resolution logos:**

1. Navigate to Settings → Security
2. Scroll to the "Brand Fetch Settings" section
3. Toggle "Use high-resolution logos" to enable
4. The setting saves automatically

When enabled, Sure will:
- Show each bank sync provider's own brand icon on Bank Sync cards, drawers, and Accounts connection cards
- Fetch higher quality logos for merchants and institutions
- Display dedicated logos for cryptocurrency assets (e.g., BTC, ETH) via Brandfetch's crypto logo service
- Use Brandfetch as a fallback for stock tickers when logos aren't available
- Display clearer, more professional-looking icons throughout the app

<Note>
High-resolution logos may increase data usage slightly as larger image files are downloaded.
</Note>

### Brandfetch integration

The Brandfetch integration provides:
- **Provider logos**: Each bank sync provider's own icon on Bank Sync cards and Accounts connection cards, falling back to a generic icon or initials when unavailable
- **High-quality logos**: Professional brand assets for better visual recognition
- **Cryptocurrency logos**: Dedicated logo resolution for crypto assets using per-coin identifiers
- **Fallback support**: Automatic logo lookup for stock tickers and merchants
- **Consistent branding**: Standardized logo appearance across all transactions and holdings

This feature works automatically once enabled. Self-hosted users must also set the `BRAND_FETCH_CLIENT_ID` environment variable. See [self-hosting configuration](/self-hosting#brand-logo-variables) for details.

## API keys

Generate API keys for programmatic access to your Sure data from **Settings → API Keys**. Each key carries a permission scope — Read Only or Read/Write — and is authenticated using the `X-Api-Key` request header.

See [API keys](/guides/app-features/api-keys) for details on creating keys, scopes, and rate limits.

## Passkeys and security keys

Add passkeys, Touch ID, Windows Hello, or hardware security keys from **Settings → Security** after enabling 2FA. These credentials can be used to sign in without email/password when passkey login is enabled, or as the second factor after email/password sign-in.

See [Passkeys and security keys](/guides/app-features/passkeys) for setup steps and self-hosting configuration notes.

## Bank sync settings

Configure third-party bank, brokerage, crypto, and data sync integrations from Settings → Bank sync. See the [providers documentation](/providers/overview) for detailed setup instructions.

## AI settings

Configure AI features like chat and transaction rules from Settings → Self-Hosting. See the [LLM support documentation](/llm-support) for more details.

## Preview features

Some newer areas of the app are gated behind preview features while they are still rolling out.

### Goals section

The Goals section is gated behind preview features. To access it, enable **Preview features** in your preferences.

1. Navigate to Settings → Preferences
2. Turn on **Enable preview features**
3. Refresh the app if the Goals section does not appear immediately

Once enabled, Goals appears in the main navigation. See [Goals](/guides/app-features/goals) for full details.

#### Reserve target: months of expenses

When creating or editing a maintained goal (such as an emergency fund), you can set the target balance as a number of months of your household's spending rather than a fixed amount.

**To use a months-based target:**

1. Create or open a maintained goal.
2. Under **Target balance**, choose **Months of expenses** instead of **Fixed amount**.
3. Enter the number of months (for example, 3 or 6).
4. Sure calculates the target balance from your family's median monthly spending and saves it immediately.

Sure recalculates and updates the target balance on the 1st of each month so it stays current as your spending changes. If your family has no spending history yet, the form keeps a manual entry field so you can set an initial target balance directly. Once spending history is available, the form shows the calculated figure instead of a text input.

Changing the number of months or switching back to a fixed amount updates the target balance right away.

#### Funding accounts and earmarks

When you create or edit a goal, each eligible depository account shows how much of its balance is still available to earmark.

- Leave the amount field blank to dedicate that account's whole balance to the goal.
- Enter a specific amount to reserve only that portion, leaving the rest available for other goals.

The hint beneath each account row tells you what the goal will claim when the amount is left blank:

- If no other goal has earmarked any portion of that account, the hint reads **"This goal will use this account's whole balance."**
- If other goals already hold earmarks on the same account, the hint reads **"This account will fund whatever is left after the other earmarks."**

If your goals on the same account add up to more than its balance, Sure shows a message explaining that they will progress pro rata — it is not an error. A goal in progress legitimately claims more than its account currently holds.

When another goal already holds a whole-account link on an account, that account shows as unavailable. You must enter a specific amount to add it to a second goal.

#### Linking accounts to a goal

When you link an account to a goal, you can either dedicate the account's entire balance to that goal or earmark a fixed amount. An account's full balance can only be dedicated to one active goal at a time. If another active goal already claims an account in full, Sure asks you to enter a specific amount instead of claiming the whole balance. This prevents the same money from being counted toward two goals simultaneously.

If you archive a goal that claimed an account in full, that account becomes available for another goal to claim in full. Restoring the archived goal while the account is already claimed in full by another goal will fail with a message identifying the conflicting goal. To restore it, either update the conflicting goal to use a fixed amount, or restore the archived goal and set a fixed amount on that account link.

#### Completing a goal

When a goal reaches its target, a celebration panel appears on the goal's page. For one-off goals (goals with a fixed target you save toward once), the panel offers a **Close** action. Closing a goal does two things:

- **Releases the earmark** — the money the goal was reserving on your linked accounts is freed. Other goals sharing those accounts can now claim that balance.
- **Freezes the reached amount** — the figure is stamped at the moment you close the goal, so spending from those accounts afterward does not walk the goal's history back.

Until you explicitly close a reached goal, it continues to reserve its earmark and compete with sibling goals on the same accounts.

Maintained goals (reserves you hold indefinitely, such as an emergency fund) are never asked to close. A maintained goal at 100% is in its normal state and keeps its reservation.

A closed goal can be reopened from the kebab menu, which thaws the frozen amount and returns the goal to active status.

#### Archiving a goal

Archiving moves a goal off the active list. An archived goal releases its earmark — any accounts it claimed in full become available to other goals. If you later unarchive a goal, Sure checks whether another goal has since claimed one of its whole-account links. If so, the restore fails with a message identifying the conflicting goal and account, so you can resolve the overlap manually.

#### Deleting a goal

You can delete a goal directly from the goal's page using the **Delete** option in the kebab menu — no need to archive it first. The confirmation dialog describes exactly what will be removed (linked accounts and pledges). Deleting a goal does not affect your transactions or account balances.

### AI sidebar on desktop

If you do not want to use the AI assistant yet, you can hide the desktop AI sidebar with the **panel-right** button in the top bar.

- The toggle collapses and reopens the right-hand sidebar
- Sure remembers your preference for future visits
- Some new users may also see the sidebar hidden by default when AI is not available

See [AI assistant sidebar](/guides/app-features/assistant-sidebar) for the full behavior.

## Appearance settings

### Dashboard layout

You can customize how your dashboard is displayed:

**2-column layout**: On wide screens, display dashboard cards in a 2-column grid for better space utilization. This setting is available in Settings → Appearance.

When enabled:
- Dashboard cards arrange in two columns on desktop screens
- Provides a more compact view of your financial overview
- Automatically adjusts to single column on mobile devices

### Drag to select a date range on charts

You can select a custom date range directly on the net worth chart or on any account's balance chart by clicking and dragging across it. Releasing the mouse navigates the page to that range. The period picker updates to show the selected dates (for example, "Aug 15 – Sep 5") instead of a generic "Custom" label. Choosing a preset from the picker clears the custom range. Drag-select is mouse-only; on touch devices, swiping the chart scrolls normally.

### Spending widget

The dashboard includes a **Spending** widget that shows your cumulative daily spending for the selected month plotted against the previous month's full curve. This lets you see at a glance whether your current month's spending is tracking ahead of or behind last month.

The widget displays:
- Your current month's running total (in green) with a marker at today's date
- The previous month's spending curve (in gray) labeled with the actual month name (for example, "August 2026"). The x-axis spans the selected month's days; if the previous month was longer, its extra days are folded into the final visible point so the endpoint still equals the full previous-month total
- The total spent so far this month and the signed delta versus the previous month, both calculated over the same number of elapsed days so the comparison is always apples-to-apples. While the selected month is still in progress, the previous-month label names the day range being compared (for example, "Aug 1–8"). Once the selected month is complete, both months are compared in full.
- Gridlines with compact currency labels and a shared tooltip
- On narrow viewports, a compact date range (for example, "Sep 01 - 6, 2026") instead of the full date range, and x-axis tick labels for the selected month only so the chart stays uncluttered

**Selecting a month:** Use the month picker in the widget header to review any of the past 12 months. The widget's selected month is independent of the dashboard's global time period at the top of the page.

The widget is hidden when there is no spending data for the selected month.

### Theme selection

Sure supports multiple theme options to match your preference:

**Available themes:**
- **Light** - Light color scheme for bright environments
- **Dark** - Dark color scheme for low-light environments
- **System** - Automatically matches your device's system theme

**To change your theme:**

1. Navigate to Settings
2. Find the "Theme" or "Appearance" section
3. Select your preferred theme (Light, Dark, or System)
4. The theme applies immediately

The theme setting is saved to your account and syncs across all your devices.

> [!TIP]
> The "System" option automatically switches between light and dark themes based on your device's settings, providing the best experience throughout the day.

## Mobile app settings

### AI chat improvements

The mobile app includes an enhanced AI chat experience:

- **Typing indicator**: An animated indicator shows when the AI is generating a response
- **Smooth animations**: The typing indicator uses a classic three-dot bounce animation
- **Auto-scroll**: The chat automatically scrolls to show new messages as they arrive
- **Improved flow**: Chat creation is now lazy-loaded on first message send, eliminating loading delays

## Debug log

The debug event log at **Settings → Debug** records diagnostic events from background jobs and provider syncs.

### Expandable table view

The log table has an **expand** button in the card header (the same pattern used by the dashboard cashflow chart). Clicking it opens the full table in a wide dialog, giving all seven columns — level, category, message, source, context IDs, and metadata — enough room to be read without truncation. The expanded view is also useful on smaller screens where the inline table is cramped.

## Data exports

Sure allows you to export your financial data for backup or analysis purposes. When you create an export, the page automatically refreshes to show the latest status.

### Export status tracking

The export list page automatically polls for updates when exports are in progress:
- **Processing exports**: The page checks for updates every 3 seconds
- **Completed exports**: Auto-refresh stops once all exports are complete
- **Download ready**: Download buttons appear when exports finish processing

This ensures you always see the current status without manually refreshing the page.

## Localization

Sure supports multiple display languages. You can change the interface language from **Settings → Preferences**.

Supported languages: English, French, German, Spanish, Italian, Turkish, Norwegian Bokmål, Catalan, Romanian, Russian, Polish, Portuguese (Brazil), Portuguese (Portugal), Chinese (Simplified), Chinese (Traditional), Dutch, Hungarian, Vietnamese, and Ukrainian.

Navigation labels update to match your selected language. For example, the System health link in the Advanced section of the settings navigation appears as **Systemstatus** when the interface language is set to German. Super-admin-only navigation items follow the same localization as the rest of the interface.

The **Settings → Background Jobs** console is fully localized in German. This includes the worker status stats panel (Workers, Busy, Enqueued, Retries, Scheduled, Dead), the in-flight operations table columns, per-operation status labels (Running, Queued, Recent, Stuck), action buttons, and all confirmation and error messages. The page title appears as **Hintergrundjobs** and the worker status section heading as **Worker-Status**.
