title: Transaction history and import limits
description: How far back Sure requests transactions, what can limit the results, and how to fill gaps
---

Sure does **not** always request all available history on the first sync. The result depends on your bank or provider, Sure's integration defaults, your settings, and pagination or processing limits. A correct current balance does not mean all historical transactions have been imported.

<Note>
Last verified: **10 October 2026**, against [Sure main at `6b4945c`](https://github.com/we-promise/sure/tree/6b4945c89d6c88897713b0fc5934c1cae78d4e37). These are source-verified defaults, not live-bank guarantees. Your installed release may behave differently. FinanceKit mobile-client query behavior was not audited.
</Note>

## How to read this reference

- **Initial request** assumes a fresh account without a custom date, unless stated otherwise.
- **Limits** distinguish Sure's implementation limits from bank/provider availability. A 30-day request window can be repeated to retrieve years of history; it is not necessarily a total-history limit.
- **Older history / later sync** explains whether subsequent syncs revisit older dates. Changing a start date or pressing Sync is not a universal backfill operation.
- Source links point to the inspected implementation. Configuration fields mentioned below are not necessarily exposed in every setup screen.

The tables cover all account-source adapter families at the verified commit, plus file-import routes. Market-price, exchange-rate, and property-valuation providers are not transaction import sources.

## Recovering older history

1. Check the source's row above and its setup page. Choose your intended initial date **before the first fetch** where the integration supports it.
2. Distinguish missing older history from an incomplete first sync. Some providers deliver data asynchronously or spread historical requests over multiple syncs.
3. Check bank-specific authorization limits. [Enable Banking explains](https://enablebanking.com/docs/faq/) that some banks allow deeper history only briefly after authorization, often about an hour, and then restrict later requests to approximately 90 days. Consent duration and transaction-history depth are different limits.
4. If the connection cannot retrieve the missing range, use a supported historical export. See [CSV and other file imports](/guides/app-features/csv-imports#importing-older-history) for preparation and limitations.

Do not delete or unlink an account merely to test history recovery. Review overlapping dates and do not assume automatic deduplication between a bank feed and a file import.
