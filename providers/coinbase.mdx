Coinbase integration allows you to sync your cryptocurrency accounts, track holdings, and monitor transactions directly in Sure using the Coinbase Developer Platform (CDP) API.

<Note>
This integration is currently in beta. Please report any issues you encounter.
</Note>

See [Transaction history and import limits](/providers/transaction-history) for initial sync defaults, history limits, and options for older transactions.

## How it works

When you connect your Coinbase account, Sure syncs:

- Account balances across multiple cryptocurrencies
- Trading history and transactions
- Holdings with real-time valuations
- Native currency support (USD, EUR, GBP, etc.)

The integration supports both cryptocurrency balances and fiat currency accounts linked to your Coinbase profile.

## Prerequisites

To use the Coinbase integration, you need:

- An active Coinbase account
- Coinbase CDP API credentials (API key and API secret)

## Getting your API credentials

1. Log in to your [Coinbase Developer Platform](https://portal.cdp.coinbase.com/) account
2. Navigate to Settings → API
3. Create a new API key with the following permissions:
   - View account information
   - View transaction history
   - View balances
4. Save your API key and API secret securely

<Warning>
Your API secret is only shown once. Store it securely - you'll need both the API key and secret to connect Sure.
</Warning>

## Connecting Coinbase to Sure

1. Navigate to **Settings** > **Bank sync** in Sure
2. Click **Connect** on the **Coinbase** card
3. Enter your API credentials:
   - **API Key**: Your Coinbase API key
   - **API Secret**: Your Coinbase API secret
4. Click **Connect**

## Account linking

After connecting, Sure discovers your Coinbase wallets through the initial sync. You can link them in two ways:

- **From Add Account**: Open the Add Account dialog, choose **Crypto** > **Coinbase**, and Sure opens wallet setup directly when there is exactly one active connection with configured credentials, or when a specific connection was selected. After you finish, Sure returns you to where you started.
- **From Settings**: Navigate to **Settings** > **Providers**, find your Coinbase connection, and open the wallet setup from there.

In the wallet setup screen:

1. Review the list of unlinked Coinbase wallets
2. Select the wallets you want to import
3. Click **Import selected** to create Sure accounts for each wallet

If more than one eligible Coinbase connection exists and none was explicitly selected, Sure returns to Provider Settings with an alert asking you to choose a connection. An unavailable selected connection or missing credentials also returns you there with an alert.

## Supported features

### Account types

The Coinbase integration supports:

- Cryptocurrency wallets (BTC, ETH, etc.)
- Fiat wallets (USD, EUR, GBP, etc.)
- Trading accounts

### Transaction syncing

Sure imports all completed transaction types from Coinbase:

| Coinbase type | Recorded as |
|---|---|
| buy / sell | Trade (Buy / Sell) |
| staking_reward | Trade (Dividend) |
| interest | Trade (Interest) |
| pro_deposit / pro_withdrawal | Trade (Transfer) |
| staking_transfer / unstaking_transfer | Trade (Transfer) |
| exchange_deposit / exchange_withdrawal | Trade (Transfer) |
| vault_withdrawal | Trade (Transfer) |
| asset_migration | Trade (Exchange) |
| send | Trade (Transfer) |

Staking rewards and interest are recorded with their real native value so they appear correctly in investment income reports. Internal transfers (moves between your own Coinbase sub-accounts) and exchanges are recorded with a zero cash amount because no purchase or sale took place.

Fiat deposits and withdrawals (moving cash in or out of Coinbase) are not imported through this integration. Coinbase wallets are modeled as crypto accounts with a cash balance of zero; fiat movements would need a separate cash account entry.

### Holdings tracking

For cryptocurrency accounts, Sure tracks:

- Current balances in native currency
- Holdings by asset type
- Real-time valuations
- Fractional quantities with up to 18 decimal places of precision

### Native currency support

The integration handles multiple currencies:

- Cryptocurrency balances (BTC, ETH, etc.)
- Fiat currencies (USD, EUR, GBP, etc.)
- Automatic currency conversion for reporting

## Security

### Credential encryption

Your Coinbase API credentials are encrypted using ActiveRecord Encryption:

- **API Key**: Uses deterministic encryption for querying
- **API Secret**: Uses standard encryption for maximum security

### API timeouts

All Coinbase API requests include timeouts to prevent hanging connections and ensure responsive syncing.

## Syncing

### Manual sync

To manually sync your Coinbase accounts, an admin can use either of these options:

- On the **Accounts** page, find your Coinbase connection card and click the refresh icon in the header row.
- Go to **Settings** > **Providers**, find your Coinbase connection, and click **Sync**.

### Automatic sync

Sure automatically syncs your Coinbase accounts on a regular schedule along with your other connected accounts.

## Troubleshooting

### Credentials need updating

If the Coinbase connection card shows "Credentials need updating", Sure could not read a configured API key and secret. This warning alone does not establish that the provider revoked a key. Click **Update credentials** in the connection card header to go to **Settings** > **Providers**, then enter your new API key and secret.

### Connection errors

If you encounter connection errors:

1. Verify your API credentials are correct
2. Check that your API key has the required permissions
3. Ensure your API key hasn't expired

### Missing transactions

If transactions are missing:

1. Manually trigger a sync.
2. Check **Settings** > **Debug** for any sync warnings. A truncated sync (rate-limited before all pages were fetched) is recorded there.
3. Verify the transaction exists in your Coinbase account.
4. For wallets with a long history, note that Sure fetches up to 5,000 transactions per wallet. Transactions older than that ceiling will not appear.
5. Staking rewards, interest, and internal transfers are now imported. If you connected Coinbase before November 2026, manually trigger a sync to import those activity types for the first time.

### Account linking issues

If you have trouble linking wallets:

1. Ensure you've selected wallets to import during setup
2. If Sure shows a "connection unavailable" alert from Add Account, the connection may have been removed or its credentials are no longer configured — go to **Settings** > **Providers** to check
3. Try syncing the connection first so Sure can discover new wallets before opening setup
4. Check that the wallet is active in your Coinbase account

## Limitations

- Sure fetches up to 5,000 transactions per wallet per sync. Accounts with more than 5,000 lifetime transactions may not have their full oldest history imported.
- If Coinbase rate-limits a sync mid-way, Sure preserves the pages already fetched and merges them with stored history. A warning appears in **Settings** > **Debug** when a sync was cut short.
- Real-time price updates depend on Coinbase API availability.
- Cost basis is not available from the Coinbase API and is not tracked.
- Fiat deposits and withdrawals are not imported (see Transaction syncing above).
